📝 单选题自动评分器 · 逐字符·按序精确对应

拖拽多个文本文件 → 与标准答案按顺序逐字符精确比对 → 批量给出每个文件的得分
核心规则（单选题，每题一个字符）：
① 答案与文件内容均先做清理：忽略大小写，并自动移除所有空格、换行、回车、制表符等空白。
② 清理后，第 1 个字符 ↔ 第 1 题、第 2 个 ↔ 第 2 题…… 严格按下标一一对应；对应位置字符完全相同（已忽略大小写）则该题得分，否则 0 分。
③ 文件字符数 < 题目数：缺的部分按错（0分）；文件字符数 > 题目数：超出部分忽略。
例：答案 Ab C → 清理后 abc（3 题）；学生作答 aB d → 清理后 abd：第1题 a=a✓、第2题 b=B✓、第3题 c≠d✗。

① 设置标准答案 忽略大小写

📌 空白和大小写不计入；答案 A B\nC 等价于 ABC，即 3 道题。文件里的作答同样自动去空白、归一大小写后再按位置比对。
① 设置全部题目分值
② 设置部分题目分值 第 题 = （如 1-3,5 表示第 1、2、3、5 题）

② 拖拽作答文件 0 个

点击此处/拖拽上传多个文本文件（txt）
作答内容为纯字符序列（如 ABCDABDDC）
或点击选择文件（支持批量）

③ 评分结果 0

导出为真正的 Excel .xlsx 文件（含「汇总排名」「逐题明细」两个工作表，中文正常无乱码）。
暂无结果，先设置答案、拖入作答文件并点击「开始评分」
