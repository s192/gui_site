这个文件里都有什么？
posThumb x / y：该学生机缩略图在教师端界面中的坐标，也就是机房里的机位 / 座位排布（x 越小越靠左，y 越小越靠前排）。本工具据此还原成座位图。
address：网卡 MAC、学生机 IP、虚拟机 IP（VMTDIP）。
name：学生姓名；未改名的机器通常显示成 IP、纯数字或 STU0xx。
signIn / platform / group：签到状态、平台类型、分组信息，编辑后原样保留写回。
